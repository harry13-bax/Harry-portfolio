# Harbakhshish Singh Arora — Portfolio

A responsive, single-page personal portfolio built with plain HTML, CSS and JavaScript.

## Preview locally
Open `index.html` in a browser. Internet access is needed for the Google Fonts; the page otherwise works as a static site.

## Publish free with GitHub Pages
1. Create a new public GitHub repository named `harbakhshish-portfolio` (or any name you prefer).
2. Upload `index.html` and the `assets` folder, keeping the folder structure unchanged.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. After GitHub Pages publishes it, use the generated URL on your applications and résumé.

## Before submitting
- Check that your email, phone, GitHub link and résumé are current.
- Add live demo / source-code links to the project cards only when you have verified public URLs. They are intentionally not fabricated here.
- This is a static portfolio; contact links open the visitor's email or phone app.
